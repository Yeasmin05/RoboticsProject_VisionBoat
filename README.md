# Robotics Project - VisionBoat

This is our robotics project named **VisionBoat**. We developed this project as part of our academic work using Arduino and different electronic components.

The main purpose of this project was to learn how hardware and programming can work together in a robotics system.

## Project Files

This repository contains:

- `glasses.ino` - Arduino code of the project
- `Project Picture - VisionBot.png` - Picture of our project
- `Robotics Project Documentation.pdf` - Full project report and documentation

## Tools and Technologies

- Arduino
- Arduino IDE
- C/C++
- Electronic components and sensors

## Project Image

![VisionBoat](Project%20Picture%20-%20VisionBot.png)

## How to Use

Open the `glasses.ino` file in Arduino IDE and connect the required components with the Arduino board. After selecting the correct board and port, upload the code to the Arduino.

More details about the project, circuit, components and working process are available in the project documentation PDF.
